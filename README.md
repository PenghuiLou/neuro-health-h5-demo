# 脑安 · 健康管理 H5（面试演示版）

移动端优先的单页 H5 体验 Demo，对应 PRD《「脑安」健康管理 H5》：**设备接入 → 健康数据采集 → 指标趋势展示 → AI 辅助解读 → 健康提示 → 用户持续管理** 的完整闭环。

> **演示模式：当前数据为模拟数据，不作为医疗判断依据。**
> 全部数据由前端本地生成，不接入真实设备、不调用真实医疗服务、不输出真实诊断结论。

---

## 一、如何运行（无需安装任何依赖）

**方式 1（推荐，最省事）**：直接双击 `index.html`，用 Chrome / Edge 打开即可。

**方式 2（本地静态服务，手机同局域网也可访问）**：

```powershell
# 任选其一
python -m http.server 5173            # 然后访问 http://localhost:5173
npx serve .                           # 需要本机已安装 Node
```

**手机预览**：用浏览器直接打开 `index.html`，或在电脑起静态服务后，用手机访问 `http://<电脑IP>:5173`。
桌面浏览器会以 390 × 844 的手机壳形式居中预览，手机浏览器自动全屏并适配安全区域。

**技术说明**：本 Demo 采用 **零依赖的 HTML + CSS + 原生 ES5 风格 JS**。
原因：当前开发环境未安装 Node/npm，为保证「拿到就能打开、离线也能演示」，未使用构建工具与 CDN；
趋势图、环形评分、睡眠阶段图、柱状图均为自研轻量 SVG 组件（`js/charts.js`），行为与 Recharts/ECharts 的用法一致，可按同名组件替换为 React 版本。
页面结构与 PRD 第 9 条要求的组件一一对应：
`HomePage` / `MetricDetailPage` / `AIDoctorPage` / `ProfilePage` / `DevicePanel` / `MetricCard` / `TrendChart` / `AIInsightSheet` / `FamilyManager`。

## 三、面试推荐演示路径（约 3 分钟）

| 步骤 | 操作 | 展示重点 |
| --- | --- | --- |
| 1 | 打开 `index.html` | 首屏即呈现「设备 + 数据 + AI 解读」闭环：设备状态、综合评分 86、实时趋势、四项指标、健康提示、小目标 |
| 2 | 观察实时采集卡 | 每 3 秒平滑刷新；点击数据点看具体数值；点「暂停采集」看暂停文案与最近更新时间 |
| 3 | 点击「睡眠质量」卡片 | 进入指标详情页（先骨架屏 → 内容）：睡眠结构、阶段分布、睡眠期间心率/呼吸趋势 |
| 4 | 切换「日 / 周 / 月」 | 月视图可左右滑动查看 30 天，含缺失数据灰区、采集事件标记、个人参考区间 |
| 5 | 切换「数据摘要」 | 数值、参考区间、质量、说明的结构化视图 |
| 6 | 点击「AI解读」 | 呼吸式加载动画 → 三段式解读（发生了什么 / 可以怎么做 / 需要注意）+ 安全边界 |
| 7 | 点击「继续追问」 | 自动把睡眠数据上下文带入「AI 医生」，自动生成有数据引用的回答 |
| 8 | 点击「如何通过科学方法提升睡眠质量？」 | 预设问题的长回答；再试「引用数据」按钮引用心率数据 |
| 9 | 返回首页 → 「添加设备」 | 搜索（雷达动画）→ 发现设备 → 绑定进度 → 绑定成功 → 同步进度 → 返回首页设备状态变化 |
| 10 | 进入「我的」 | 健康档案完成度、设备管理、家庭管理（授权范围、邀请三步流程、撤回授权） |
| 11 | 打开「关于我们 / 隐私说明 / 联系我们 / 常见问题」 | 公司介绍（杭州演化医疗设备有限公司）、数据边界与合规表达 |
| 12 | 「演示控制台」 | 一键演示空状态、同步失败错误态与重试、重置演示数据 |

## 四、产品与合规边界（已落实到界面文案）

- 所有指标页、AI 解读、月度报告均标注「模拟数据 / 仅用于健康趋势参考 / 不构成诊断或治疗建议」。
- 不使用「确诊、治疗有效、脑供血不足」等未经验证的医学结论；异常数据一律提示**复测、观察趋势、必要时咨询专业人士**。
- AI 医生定位为「脑安 AI 医生 · 健康科普与数据解释」，页面固定展示安全提示，不做疾病判断与用药建议。
- 家庭共享必须经被关注成员授权，可见范围可选「全部数据 / 睡眠数据 / 仅异常提醒」，可随时调整或撤回。
- 演示数据、家庭邀请码、邮箱均为虚构内容，不连接真实设备与真实医疗服务。

## 六、部署到 GitHub Pages（任意设备浏览器都能打开）

仓库地址：`https://github.com/PenghuiLou/neuro-health-h5-demo`

**开启 Pages（只需一次）**

1. 打开仓库 → **Settings** → 左侧 **Pages**
2. **Build and deployment → Source** 选择 **Deploy from a branch**
3. **Branch** 选择 `main`，目录选择 **`/ (root)`**，点击 **Save**
4. 等约 1 分钟，访问：

```
https://penghuilou.github.io/neuro-health-h5-demo/
```

> 路径必须全小写（GitHub Pages 的域名与仓库路径区分大小写）。`index.html` 已放在仓库根目录，无需任何额外配置。

**后续更新内容**

```bash
git add -A
git commit -m "更新演示内容"
git push
```

推送后 Pages 会自动重新发布（约 1 分钟即可看到最新版本）。

**说明**

- 站点是纯静态文件（HTML/CSS/JS + 自研 SVG 图表），不依赖 Node、不依赖 CDN，全球节点直接托管。
- 手机浏览器打开后自动全屏并适配安全区域；桌面浏览器则显示 390 × 844 的手机壳预览，方便面试现场演示。
- 页面内的所有健康数据、AI 回答、设备状态均为本地模拟，界面多处标注「演示模式：当前数据为模拟数据，不作为医疗判断依据」。
